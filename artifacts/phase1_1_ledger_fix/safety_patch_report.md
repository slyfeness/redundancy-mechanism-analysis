# Phase 1.1 证据安全补丁

**状态：`ENGINEERING_PASS / JUDGE_PENDING_HUMAN_REVIEW`**

本次在 PR #3 的 `eaf2622f61cc56ecc5c512f18a1b6521ac604e64` 基础上验证运行时的证据安全边界。验证材料为合成夹具、冻结成果的 Git 差异检查和 Schema 静态检查。

| 边界 | 运行时行为 | 合成验收 |
| --- | --- | --- |
| 整体不确定性 | 默认保留全局风险。只有返回全文、账本已识别候选和任务约束可明确绑定时才允许局部化。事件保留原始错误、编号、内容摘要与风险范围，`effective_gain` 为 `null`。 | 全局和局部记录、错误范围反例、已验证事实保留、`g` 弃权、重复调用禁计价均通过。 |
| 非法证据行 | `TaskSpec` 之外的编号、缺失候选与不可定位行进入全局风险。有明确合法坐标的未知状态进入局部潜在冲突。其余合法行独立写入，固定分母不变。 | `C999`、缺失候选、未知或类型错误状态、非对象行、有效支持与潜在反证同批均通过。 |
| 历史风险与计价 | 判定使用动作前、动作后风险的并集。全局风险、未知目标下的局部风险、目标事实风险及出现在本次返回中的风险都会使事件弃权。记录原因、风险引用和禁计价标志。 | R1 不触发核对，相关 R2b 即使精确重复也弃权。独立风险与无风险用例都保留正常 R2b，且 R2b 优先于 R1。普通成功和并行分支合并均保留风险。 |
| 最终答案锚点 | 两个半开字符区间都与原文逐字绑定，候选必须覆盖唯一提交的答案值，锚点必须覆盖完整提交结构。 | 伪造锚点、位置不一致、讨论片段、重复提交、多个候选均被拒绝。单一标签、答案标签块和短答案可验证。 |

行为模型保持保守。自由格式回答、无可靠锚点或省略坐标的新版响应可能多弃权。全局风险持续阻断相关判别和 `g`，本轮未引入自动消解。版本、已支持格式、兼容边界及旧缓存处理见 [协议迁移说明](protocol_migration.md)。

测试覆盖从正常 R2b 到奖励预览的人工批准门槛。空批准表不会产生局部扣分，合成 `PASS` 对照在同一夹具上才出现预览扣分。两种预览的 `formal_training_usable` 均为 `false`，优化步数均为 0。

冻结的一期结果、诊断、Ledger-GRPO 历史结果和旧验收报告通过基准版本差异校验。没有访问真实数据或受控缓存。新增模型请求、真实数据重跑、GPU 作业、轨迹生成和策略更新均为 0。真实 Judge 质量等待独立评估及人工批准。测试明细见 [机器可读结果](safety_patch_tests.json)。
