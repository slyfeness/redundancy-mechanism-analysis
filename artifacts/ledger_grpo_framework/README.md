# Ledger-GRPO 试跑结果

框架的 [源码与运行说明](../../ledger-grpo/README.md) 包含任务适配、证据账本、事件计价、训练与评估入口。以下结果来自既有运行，原始作答、模型缓存、逐题金标和凭据按原权限保存。各来源文件的 SHA-256 见 [来源回执](source_receipts.json)。

| 运行 | 核对结果 |
| --- | --- |
| [历史 P0 计价回放 182501](event-price-audit-182501.json) | 1,717 次记录工具事件中 1,623 次可计量。359 次精确重复中 306 次可计量。 |
| [单步训练试跑 182516](pilot-182516.json) | 五个训练臂每个完成一次更新和检查点保存。固定评估每臂 16 题、128 个样本，只有一个训练种子。 |
| [合成流程验证](synthetic-smoke.json) | 6 条合成轨迹通过账本、奖励和评估接口。 |

试跑的原始评估中，P0 准确率为 32.81%。训练臂记录里的准确率字段均为 0，后续对照回执将准确率差异标为 `unresolved_outcomes`。独立模型对正常提交进行了离线盲评，P0 为 32.81%，`outcome` 为 30.47%，`targeted` 为 32.03%。`targeted` 相对 P0 的按题配对差值为 −0.78 个百分点，95% 区间为 [−4.69, +3.13] 个百分点。这些是探索性模型复核结果，原判定仍在对应字段保留。

`targeted` 的平均工具调用为 12.57 次，P0 为 12.27 次。一次更新和一个训练种子的结果只能检验流程，尚未建立正确率非劣效或节约工具调用的证据。R1 与 R2a 在该试跑中的计价均为零。

当前源码在本地运行了 305 个测试，304 个通过，1 个可选 TensorDict 容器测试跳过。
