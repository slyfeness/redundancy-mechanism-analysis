# PEER029：从已知、判断到真正派工

十案逐案判定在CURRENT_ADJUDICATIONS，来源与SHA在01_CASES.csv；四支成本由CURRENT_COSTS复算。此文是Codex跨案解释，不是人工金标准。数量以BATCH_COUNTS.json为准，不手填总数。

## 相似工作为何有不同作用

**整体判断不等立即停止。** 18末段、68和231目标都实际作完整接受，四新也都恢复判断。18无新工具但全更长；68仍查疾病，231有零、一次或两次真实取证。省或增加的工作必须落到之后的查询实例与表达，不能把“认知重建”当结论终点。

**已有主体下补证，增量不一样。** 1135目标第一次核日期并算半年，四新均恢复；一支同Return覆盖军方与选举，一支同批两Call，不能混淆共享证据与少Actor。170原实际核到Dan职业，四新却都没再核该条件，改取已知季数，有的另获署名；核心C不代表原证据路径保持。202原六查也未补精确条件，G提前接受后零或两查，答案仍C但博士日期/电影数量未齐。

**错误限定怎样制造工作有明确正反对照。** 205new1说题目要求WesternCape，实际按该省反复核城镇，Gauteng返回没改掉前提，核心女校最终仍C而工具/Prompt增加。724new2从不符Fisher借Philadelphia继续寻找其他人，没有宣称题目就要求该城，不能同样认错误硬限定。724new4排Crile后确实还查其教育，但最终仍拒答，重查不是重新接受。

**找到正确人和作答是两道关。** 853new1首广Query就得Larson，后续泛查未证论文关系，仍按最可能提交C；new4晚两次得到且真实具名核查，末明确拒答W；另两根本没有Larson却选择Pinar。三未答对并不是同一种“正确材料没有采用”。局部资格能被当成足够身份依据时，可以核心C也可以W，必须与具体关系支持分开。

## 教师补偿分开看

- 205的正确学校在P只是可见，G点名使采用可能被补偿。
- 202的G不提供新姓名却预填充分性结论。
- 724的G提供P没有的Crile/1921关系，但四支即刻识死亡不符，提示不强制接受。
- 853的G仅重读方向，不含Larson，正确候选是真实新Return获得。
- 18末段G0，只能和同条件比较，不冒充教师引导结果。
