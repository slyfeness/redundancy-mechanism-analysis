# PEER_031：关系分工、真实补证与已知事实重新派工

本批逐案语义记录已分别保存，全部四次续跑的具体判断、真实调用与成本有位置证据。这里汇总比较；数量只由BATCH_COUNTS.json复算，不手写总体结果。八A、两B，九FIRST_SENTENCE、一TERMINAL；两个CHAR边界按区间，其他原生精确。

**同样重新取得原资料，恢复的未必是同一套行动关系。** 528的专辑资料与工作坊人名四次均重新取得；1/4修复最初的合作者生日想法后再真实查询，2已查错两人后修复，3却在已读正确工作坊生日后仍十次查合作者生日。主体四次正确，增加费用仍有具体来源。202同样有正确人物恢复后，未证Tory合作继续触发相同查询到无Final的路径。这与“原功能重建”并不冲突，后者不是机制分析终点。

**有些额外核验真实补了原答案漏核的约束。** 170末段G0四支都重做整体判断；三支发现producer条件尚无依据，真实80759补到AssociateProducer才答。另一支只重新核已用季数，虽返回署名却没有采用。这提供同一工具数量下不同信息产物的对照。724成功支新取得Clarke多关系后只余死亡，真实补1970后即提交，不能因又查一次就归低收益循环。

**少一次工具不等于未知条件已消失。** 231的P已接受Mando，接教师提交框架后四零Call；省了一次原专辑取证，但专辑/父亲关系仍无证。四支无实质新推理、短复述和完整比较不同，使相同工具减少下的生成节省大不相同。506一支同样不查声音关系，其余三支仍查且有教育生平增量，无法一概解释为必要功能已无作用。

**G需要查事实、角色和前件，而非只查新人名。** 289提前给出原U新剧目且覆盖整段后继Reasoning计划；18强化P已见而未采用的人物；724提前给出U才取到的Harvard朋友端点；528不带新名字却失去these musicians的原前件。以上都是不同补偿或解释风险，不能合计为自然无引导的冗余证据。

**B类的状态变化不是单一丢失正确工作。** 724原拒答，四支为正确、无Final、拒答、无Final；853原拒答，仅一支正确、另一拒答、两无Final。853两支很早采用正确导师并真查询仍因论文关系未闭继续耗预算；成功支同样没有核全论文，只最终允许带缺口回答。不能把三个C/W/N变化写成三个正确性改善，更不能因B而认原失败候选测试不可少。
