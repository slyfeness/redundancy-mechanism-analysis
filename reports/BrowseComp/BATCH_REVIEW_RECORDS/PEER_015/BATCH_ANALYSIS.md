# PEER 015：同一结果标签背后的不同判断与行动

十案的四条续跑均已分别亲写并通过精确引用和成本核对。BATCH_ANALYSIS.json保留具体功能、前态比较、明确机制成员及反例；BATCH_COUNTS.json由程序复算。Codex判断不是独立人工金标准。

本批A并非全都已知事实复述。1135的协议Stage首次建立国家锚点，18的初查却失败，身份采用在更后面；637/853是正确核心后的未证关系取证，970则是失败取证之后独立回到人物整体比较。把它们都称核验会遗漏工作真正改变的状态。

970三支恢复整体人物比较并提交，一支只持续导演核验至N。但原U不是首次采用或唯一停止决定，三个C还把未证导演属性补成事实；不能将比较出现当充分解释。495的对照更清楚：三G0支恢复祖母非父母的正确逻辑，却零Call继续猜到当前剩余2541Token，一支不纠错反而执行16次真实泛查询到Context。逻辑纠正、信息获取、答案提交是分开的衔接点。

B中，1122new2真正用Greek迁城传记修正国家并改查正确夫妻，1188new2真正采用38/正确季集却太晚，266new1终于把P博客名用于真实Query却没有下一Actor消费Return。这三种N都不能写成没有采用证据；同时，1122新1正式拒答W与原猜DorothyW内容不同，1188新3无证猜剧W与原无Final也不是准确率改善。

成本按执行方式解释。1078new2、266new2新增一轮10000Token纯计划，没有新Call；1122new3、495new1是同反馈后仍真实重复检索，累计输入明显增加。495后三只有原同轮剩余2541Token，不能用整条原10000当后缀基线。1188两个G0正确分支更少Search/Actor却更多生成，因为补正确关系与正式回答替代旧短重复；不同成本维度不应揉成一句更省。

仍不能唯一解释的地方保留：为何某次回到整体接受、为何正确解释再被错误表述替换、为何原有足够线索晚到真实Query、为何有时纯计划有时真工具重复。机制图谱只吸收有具体前态—判断—行动证据的链接，不用同结果、同词或重建标签填空。
