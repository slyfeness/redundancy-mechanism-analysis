# 全340组跨题作用链对齐口径

这是本次读完340份自由关系记录后的统计对齐口径，不是Stage新切分规则、预设Pattern分类器或独立人工金标准。不修改原边界、原评价或原自由记录。

每组仍保留前态→工作→判断→行动→结果/成本的原描述；以下代码只把有相同中间过程的证据链接起来，允许多重归属、反例、未知及不归类。不能由A/B或C/W/N反推机制。Python只做标识符定位、引用校验和计数。

- M01：材料/关系从可见到实际采用，并改变真实查询对象或答案依据。需定位采用或未采用及其行动后果；不因正确实体出现就算。
- M02：对对象、角色、事件或范围的具体解释成为工作前提，决定查谁/查什么或公式用哪个输入。错误绑定、修复和合理题义歧义分别保留；只有错误想法、没有行动/输入后果不足。
- M03：实际读取范围或片段覆盖与所需证据不匹配；短窗/不含字段的文档继续被读，或者扩大范围/换真实片段后目标句才进入输入并被采用。正确DocID不等于已见目标句。
- M04：已获得的失败/不足反馈是否落实为新的有效取证决策，还是重复同返回入口或停在意向；需真实前后Query/Return/处理。微调词相同不自动认定重复，不把所有失败查询视为无价值。
- M05：剩余条件被用作推进或提交的关口，决定继续核验、条件推进、重开接受或实际提交。须明确具体缺口及真实下一动作；核心真缺口、侧条件未证、额外自加要求分别说明，不能笼统把所有停止行为归一机制。
- M06：相关判断在P中已明确形成/采用之后再次确认，没有新增判断或行动更新；删后取消该执行实例或以较短重复确认继续。首次采用在后续重建不计此机制的正例。新增独立证据不能当无增量确认。
- M07：候选违反具体条件的冲突被识别后，是否真正限制后续查询/接受；冲突修复、重接收、仅说出冲突但不约束行动区分。普通不同、无据怀疑不算。

R01为跨机制成本解释字段，不当新的答案作用机制：同功能重建但通过较少执行、合批、短表达或后续少展开完成。必须定位实际减少，不把FULL恢复当不能节省，不把原Stage长度当净节省。

每条模型记录提供unit_id、mechanisms列表。每项含mechanism_id、支持的原自由relation_indices（0-based）、support_repeats、counter_repeats、uncertain_repeats、specific_state_update及limit。反例是对所写具体有条件链的反证，不自动等于其余四减支持。一个续跑可展示链条前半并反驳其充分性，原文解释保留。

G提示/实体/确定性补偿、原新采样与预算差、证据质量不足、非原生字符切点作为独立审计限制，不能计为自然推理共性的无条件支持。

## 统计前的作用位置核对

每条链接另由模型明确target_relation：DIRECT_U（原U实际承担该动作，四路对照检验其恢复/替代/缺失）、DOWNSTREAM_ONLY（链条只在别的原后续或新后续发生，不能据此给被删U归同类功能）、UNCLEAR（U至该链的连接未明确）。字段只定位工作关系，不表示因果证明。先分位置再统计；DIRECT_U的Stage/题目支持数与所有后继观察数分别输出，禁止将后继出现的重复搜索反推为被删Stage本来冗余。U整体功能仍以原自由记录的function/prestate/transition为准。

统计分A/B、干预条件、原状态→新状态，Stage/不同question_key/原轨迹/续跑分别计数；多重归属不相加为唯一Stage总数。未归类或未知完整留表。自由关系与新链接均由Codex阅读后直接书写，程序不得按关键词或固定字典自动生成。
