**[已验证]** 217 次调用中，52 次（23.96%）命中重复规则，涉及 8 条轨迹；其中 51 次来自用满预算的轨迹。**[推断]** 这是规则命中率，不能直接解释成可安全删除率。

|规则|次数/调用占比|生成 token/生成占比|已知返回 token/已知返回占比|
|---|---:|---:|---:|

¹ 并集为 S_exact、S_allseen、O_exact、O_samecontent；本批 S_exact 全包含在 S_allseen。查询按小写、删除 Unicode 标点、折叠空白规范化；Open 正文哈希不规范化。按调用派发顺序比较，本批没有同轮匹配命中。

分母：89,695 生成 token（含未完成生成的 20,000），114,056 **已知**返回 token。7 个末尾返回缺少上一轮口径所需的下一输入计数，未填 0；其中 4 个落在重复并集。并行共享的 621 个生成 token 不重复分摊，本批未落在规则命中轮次。返回成本比例仅针对已知量。

**[已验证]** 正常交卷重复 1/77；用满预算 51/140；未完成生成 0 次调用，重复比例不定义。按已有判分：答对 1/71，答错或未交卷 51/146；提交但答错者 0/6。重复最多三条占 35/52（67.31%）。完整分组和逐轨迹成本见 [summary](redundancy_summary.json)。**[推断]** 抽查 8 个 S_near，仅 2 个仍找同一信息，6 个改变属性或范围，不能直接扣分；见 [例子](redundancy_examples.md)。

## 3. 原子条件试拆（T3）

**[推断]** feature 可用作拆分锚点，不能直接作事实金标。10 题拆出 132 条：112 条有 feature 锚点（84.85%），20 条 prompt_only（15.15%），46 条带歧义（34.85%）。逐题条件、变量、证据标准见 [试拆清单](atomic_conditions_pilot.json)。
