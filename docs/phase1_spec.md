# 第一期范围

输入是冻结的自然作答原始捕获和独立结果。每个串行调用及其返回构成一个工具 Stage，平行调用保留组与独立调用编号，最终自然答案单列。返回成本只归属原事件，只有原生生成位置进入策略坐标。

动作目标使用当前调用前的信息。账本只从可追溯工具返回获得事实。R1 标记对已支持且可见事实的无增量复核。R2b 比较同一受验证工具环境下的有效参数和完整有效返回。R2a 的近重复检索只报告诊断。保护原因优先，计价选择 R2b 再 R1。

结果优势采用独立 `Y` 和题内留一基线。同伴至少一条正确时，已批准事件可在其确定的调用区间应用加性扣分。轨迹内基础价总量上限 0.5。开发集事件成本中位数用于成本系数，工具文本位不进损失。

工程与标签质量分别验收。精确率至少 90%，必要动作误标不超过 5%，旧实验的 B⁺ 被标记率与污染率单列。按题重采样，样本不足和未完成人工审查分别保留状态。全过程只执行离线判别与奖励计算。
