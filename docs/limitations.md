# 已知限制

- 并行调用共享模型生成区间，保留组内调用和各自返回。这类组无法无歧义归属的策略位置不计价。
- 有文本而没有原生 ID 时可做离线判别，策略位置不可验。缺失权威分词器时也可能无法验证调用包络和返回 Token 成本。
- 账本的语义状态来自本地 Judge，字符引文校验只验证引用身份，语义正确性需独立人审。
- 未回注给 Actor 的工具返回有记录，当前可见性和增量置信度会受影响。历史证据与当前请求仍可见的证据分别保留。
- TOKEN15 只有在同源哈希及区间可追溯时才能映射。旧删除状态还需经过人工核对，包括后继引导和功能重建，才能关联到 B⁺/B⁻。
- 奖励预览是离线数值测试。对训练、运行成本、正确率和停止行为的效果需要单独验证。
