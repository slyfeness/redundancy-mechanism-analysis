# 冗余 Judge 第一期实施计划

**目标**：对冻结的 BrowseComp-Plus 自然轨迹进行离线工具级标注，输出逐条证据、人工复审材料和无优化器的奖励预览。

**结构**：原始数据从只读适配器载入。解析层保全原始位置，语义流程按阶段前缀推进。审计、奖励与发布仅消费冻结产物。

**规格**：[Phase 1](../../phase1_spec.md)。

- [ ] 清点 100×4 作答、独立评分、TOKEN15 与本地模型。Slurm CPU 固定题级划分、资产哈希和语料索引。
- [ ] 解析原生响应、并行调用、缺失返回及旧分块重叠。测试位置、可见性及返回归属。
- [ ] 测试并实现任务约束、动作目标、证据增量、标签和轨迹汇总。用前缀测试隔离未来返回。
- [ ] 验证奖励留一优势、同伴门控、局部区间、同事件去重及价格封顶。实现证据不足时的批准规则。
- [ ] 使用真实本地判别器跑开发集五题。独立核对引用和失败记录后冻结；按固定划分覆盖全集。
- [ ] 导出自然及保护人工审计任务和有回执的奖励预览。
- [ ] 校验 ZIP、输入哈希及脱敏提交，推送指定分支并交付 PR 和发布附件。
