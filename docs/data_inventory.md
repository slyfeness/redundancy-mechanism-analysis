# 数据清点

祝融 CPU 作业 184746 校验 BrowseComp-Plus 冻结的 100 道题及全部 400 个原始作答，读取各自的历史独立结果。原始结果为 C 113、W 39、N 246、未定 2。4,791 个模型响应都有原生 ID，384 个响应包含多个调用，共 5,114 个工具事件。

固定划分为开发 60 题、校准 20 题、审计 20 题。分组采用规范化题面和字符相似度／词项交并比的近重复连通分量，固定种子 20261113。此阈值下没有检测到跨组近重复。

原检索器的固定语料与索引载入有历史稳定性回执。观测到 291 个相同查询返回相同的复查事件，语料清点未见同轨迹同参数返回变化。该证据限定于此历史批次。

旧 TOKEN15 清单与分支结果可访问，清点阶段的源轨迹 SHA-256 交集为零。以题目 ID 或题面关联不足以安全继承删除标签。模型权重、原文轨迹与完整清点索引保存在授权集群存储。
