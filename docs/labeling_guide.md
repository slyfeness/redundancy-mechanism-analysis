# 人工标注

1. 从 `human_review_template.csv` 按事件编号查对应的 Stage、调用前账本、原始调用与返回、历史可见证据。评审前避免打开含自动判别的采样清单。
2. **R1**。已有可见证据充分支持同一候选和约束，再查相同事实且未补强证据记阳性。独立佐证、同名候选、信息已裁剪、尚有冲突均需保护。
3. **R2b**。相同已认证环境、同工具、同有效参数、同有效返回，而且旧返回当前可见，记阳性。动态数据、错误恢复、总结转全文和合理重试需要保护。
4. **R2a**。同一缺口、指向相近查询、此前有尝试且本次未获增量。保留诊断，永不计价。
5. 保留 positive、negative 或 abstain。填写 necessary、protection_reason、独立评审 ID。需要裁决时添加独立裁决人记录，保留原评审。
6. 将已完成的人类记录导出为 JSONL，配置 `human_annotations` 后运行 audit。同一事件的自然样本和保护挑战样本分别记录。

例如，已经打开原文明确确认组织成立年份，随后在原文依然可见时用同一查询得到同一返回，可标 R2b。只看到搜索摘要后打开全文属于新证据获取。工具返回缺失或目标存在多种解释时应弃权。
